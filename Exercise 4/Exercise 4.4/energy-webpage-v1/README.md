## Generative AI Reflection

### Tools Used
* **Generative AI Assistant (Gemini / GitHub Copilot)**: Used for layout guidance, HTML5 semantic structuring, CSS styling, and feature implementation.

### Purpose and Usage
Generative AI was integrated into the development workflow for the following tasks:
* **HTML Structure**: Assist in providing HTML5 semantic markup for all web pages
* **CSS Layout & Styling**: Suggestions on how to use CSS Grid, Flexbox, and CSS variables for developing a responsive design.
* **UI Components & Enhancements**: Development of interactive UI components such as hover effects for logos, favicons for browser tabs, card and contact forms.
* **Javascript Logic and DOM Manipulation:**GenAI was used in assisting to create the energy calculator with vanilla JavaScript in relation to capturing events from form submission, user input validation, and DOM manipulation.

### Adaptations and Manual Changes
Altough GenAI was used to assit in creating initial structural templates and styles, a number of manual changes were implemented:
* **Asset Path Corrections**: Adjusted generated filepaths such as 'assets/img/logo.png' and 'assets/css/styles.css'.
* **Styling Fine-Tuning**: Changed color values, font size, padding, and duration of transitions in order to maintain consistency of site design in 'index.html','televisions.html', and 'about.html'
* **Responsive Layout Adjustments**: Adjusted the grid layout and breakpoint to make sure components render properly on mobile devices, tablets, and computer screens.

### Key Learnings
* **Semantic Web Standards**: Learned about the need for HTML5 semantic tags to increase accessibility and keep the content seperated from the styling.
* **Modern CSS Techniques**: Applied my skills using native css variables, Grid, and Flexbox to create flexible page layouts
* **Favicon Integration**: Learned about linking and formatting browser tab icons through the use of '<link>' elements in HTML.
* **Vanilla JavaScript Implementation:** Gained a good understanding of how to read user inputs from the DOM, do mathematical calculations on the client side, and write the outputs back to the webpage.

### Limitations and Challenges
* **Placeholder Assets**: Code generated by default had generic images or links which needed replacement with real file references for the projects.
* **Generic Styling**: Default style recommendations sometimes turned out to be quite basic and required manual customization to fit the requirement.
* **Cross-Page Consistency**: Had to manually check for consistency across multiple HTML pages for common elements such as navigation in header states and footer.

### Extensions Completed
* **Interactive Appliance Energy Calculator:** Developed a custom calculator using only vanilla JavaScript. It enables the user to enter the appliance wattage, number of hours the appliances is used each day, and the cost per kilowatt hour of power to compute their daily/yearly power consumption in kilowatt hours and yearly cost.
